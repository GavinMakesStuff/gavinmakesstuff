Setup guide

Follow these steps once to get analytics tracking on this site.

1

Create a Google Analytics account

Go to analytics.google.com, sign in with your Google account, and click "Start measuring." Choose a property name, set your timezone and currency, then create a Web data stream for this site.

2

Copy your Measurement ID

In GA4 → Admin → Data Streams → click your stream → copy the Measurement ID (starts with G-). Paste it into the field above and click Save & Apply.

3

Nothing to do here — the tracking script installs itself

Every page on this site loads a shared script (js/shared.js) that reads the Measurement ID you just saved and injects the tracking snippet automatically — no manual copy-pasting into each page's <head> needed. The exact snippet it injects is shown below for reference (useful mainly if you ever add a page that doesn't load the shared script).

Enter your Measurement ID above to see the code snippet.
4

Verify data is coming in

Visit the site, then check GA4 → Reports → Realtime — you should see yourself appear within a minute or two, since the script is already live. It can take 24 to 48 hours for full historical data to populate. Enable "Exclude my own visits" above first so your own visits do not skew the data. This step can't be auto-verified from here — check GA4 directly.

Local Launch Guide

How to run each app on this machine, for a preview or dev session.

Marginalia

Python / Flask

Location: Desktop\Apps\Marginalia

cd Desktop/Apps/Marginalia
python webapp/app.py

Runs at http://127.0.0.1:5000 (Flask default). Run from the Marginalia root, not from inside webapp/, since app.py imports from the parent directory.

Env — copy .env.example to .env: GMAIL_ADDRESS, GMAIL_APP_PASSWORD, KINDLE_EMAIL required; ANTHROPIC_API_KEY optional (Highlights Workspace only). Dependencies: pip install -r requirements.txt.

Balance (Finance Tracker)

FastAPI + React

Location: Desktop\Apps\Balance

Legacy local/live split. local/ and live/ are separate, manually-synced copies. Default to local for dev/preview — live mirrors production and isn't updated automatically. Syncing means a full code copy (robocopy, excluding db/build/node_modules), not a cherry-pick, since local's codebase is fully integrated.

Desktop/Apps/Balance/local/Start App.bat

Starts backend (uvicorn main:app --host 0.0.0.0 --port 8000 --reload) and frontend (npm start, opens http://localhost:3000) together. First time only: run Setup (Run First).bat.

live/ also has its own .claude/launch.json entries (balance-live-backend port 8000, balance-live-frontend port 3000) — same conceptual ports as local, so don't run both sides at once without changing one's port.

gavinmakesstuff (this site)

Static + Vercel functions

Location: Desktop\gavinmakesstuff

A — static-only, for anything not touching the admin panel or /api/*:

npx serve .

B — full parity, needed for admin login and any API work (this page included):

vercel dev

One-time setup on a fresh machine: vercel link, then vercel env pull .env.local — don't hand-type OAUTH_GITHUB_CLIENT_ID, OAUTH_GITHUB_CLIENT_SECRET, ANTHROPIC_API_KEY, GITHUB_REPO, ALLOWED_GITHUB_USER.

Anami

Location: Desktop\Apps\Anami
