Scout

Accessibility Statement

Last updated: August 26, 2026

Scout is operated by Gavin Krohman, an individual sole proprietor based in Vancouver, British Columbia, Canada. We want Scout to be usable by as many people as possible, including people with disabilities, and we're committed to meeting the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA.

1. Conformance Target

We're targeting WCAG 2.1 Level AA across Scout's public pages and the core app. This is an ongoing goal rather than a guarantee — as a small, solo-operated tool, Scout hasn't had a full independent accessibility audit, and some areas may not yet fully conform.

2. Measures We Take

  • Semantic HTML structure and heading hierarchy on public and app pages.
  • Sufficient color contrast between text and background in Scout's teal/sand palette.
  • Keyboard-operable interactive elements (forms, buttons, links) where standard HTML controls are used.
  • Readable, resizable text set in the Nunito typeface, without relying on fixed pixel sizing that blocks browser zoom.

3. Known Limitations

Scout hasn't been through a formal accessibility audit, so there may be gaps we're not yet aware of — for example around screen-reader labeling on some interactive analysis results, or focus handling in dynamic UI states. We're actively working to identify and close these gaps over time.

4. Reporting an Issue

If you encounter an accessibility barrier while using Scout, please let us know — specific details (the page, what you were trying to do, and your browser/assistive technology) help us fix it faster. Email gavinmakesstuff@gmail.com and we'll respond as quickly as we can.

5. Changes to This Statement

We may update this statement as Scout's accessibility work progresses. If we make material changes, we'll update the date above.

This statement reflects a good-faith, in-progress effort by a small, solo-operated tool. It hasn't been reviewed by an accessibility professional or lawyer — if Scout grows, a formal audit against WCAG 2.1 AA is worth commissioning.
